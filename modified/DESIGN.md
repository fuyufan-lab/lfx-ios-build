# 老鳳祥 · 内容系统设计规范

> 基于 Open Design craft rules 构建的珠宝品牌移动端 Web 设计系统

## 1. 品牌气质

传承百年工艺的高端珠宝品牌，数字化触点应传达：**精致、克制、值得信赖**。
- 视觉风格：温暖轻奢、杂志质感、移动端优先
- 色彩立场：暖金色调为主，大面积中性底色
- 设计意图：让用户感受到品牌底蕴而非科技平台感

## 2. 色彩

### 色板结构（四层）

| 层 | 占比 | Token | 色值 |
|---|---|---|---|
| **中性色** | 70–90% | `--bg` | `#faf9f6`（暖白纸张色）|
| | | `--surface` | `#ffffff`（卡片）|
| | | `--fg` | `#2f3430`（近黑微暖）|
| | | `--muted` | `#777c77`（中灰）|
| | | `--border` | `rgba(113,92,31,0.08)`（极淡金线）|
| **强调色** | 5–10% | `--accent` | `#715c1f`（古金色）|
| | | `--accent-light` | `#fde095`（淡金色填充）|
| | | `--accent-dim` | `#eed289`（渐变端点）|
| **语义色** | 0–5% | `--success` | `#4a7c3f` |
| | | `--error` | `#9e422c` |
| | | `--warning` | `#d97706` |
| **特效色** | <1% | 渐变仅限PK进度条和英雄区 |

### 强调色纪律
- **每屏最多 2 处可见 `--accent` 使用**
- 典型组合：一个标签/芯片 + 一个主 CTA
- 链接在有 CTA 的屏幕上降级为 `--fg` 下划线
- 不使用 Tailwind 默认靛蓝 `#6366f1`

## 3. 排版

### 字体系统
- **Display/标题:** Manrope（现代几何无衬线，适合数字产品标题）
- **正文:** Manrope（统一品牌感）
- **标签/数据:** Inter（高辨识度等宽数字）
- **代码/标签:** JetBrains Mono

### 字号层级（三级模型）

| 层级 | 角色 | 字号 | 字重 | 字间距 |
|---|---|---|---|---|
| **Primary** | 入口点 | 24px / 20px | 200-300（轻）| -0.02em |
| **Secondary** | 结构 | 14px / 12px | 400-500 | 0.1em+（大写标签）|
| **Tertiary** | 辅助 | 10px / 9px | 400 | 0.02em |

### 排版纪律
- 每个视觉区域只有一个主导入口点
- 标题使用 `font-light`（200-300），不用 bold 堆砌
- 标签文字大写 + 宽字间距（`tracking-[0.25em] uppercase`）
- 层级靠字重跳跃传达，不靠逐步递增（weight should jump, not step）

## 4. 间距与网格

### 间距比例尺
`4 / 8 / 12 / 16 / 24 / 32 / 48`

### 分组节奏
- **组内间距：** 8–12px（元素紧密关联）
- **组间间距：** 24–32px（视觉分组明确）
- **板块间距：** 20px（`mb-5`，各板块之间）

### 纪律
- 保持垂直韵律一致
- 不要所有 section 用相同间距（打破均匀 = 层次信息）
- 内边距 ≥16px（卡片/区块内部）

## 5. 卡片与组件

### 卡片
```
背景: #ffffff
边框: 1px solid rgba(113,92,31,0.08)
圆角: 0px（品牌方角特征）
内边距: 16-24px
阴影: 无（平面优先）
hover: y+2px, blur 16, fg-at-6% opacity（唯一抬升场景）
```

### 按钮
- **主操作:** `--accent` 填充，`--on-primary` 文字，0px 圆角
- **次操作:** 1px `--accent/20%` 边框，透明填充
- **破坏操作:** `--error` 文字

### KPI 卡片
```
背景: 线性渐变(135deg, --accent 0%, --accent-dim 100%)
文字: --on-primary 白色
圆角: 0px
内边距: 16px
```

### 进度条
- PK排行：6px 高，3px 圆角，`--accent` 或 `--secondary` 填充
- 过渡动画：width 0.6s ease

### 底部导航
- 固定底部，毛玻璃背景 `backdrop-blur-xl`
- 激活态：`--accent` + FILL 1 图标
- 非激活态：`stone-400` + FILL 0 图标

## 6. 动效

### 时长表

| 时长 | 用途 |
|---|---|
| 50–100ms | 即时反馈（hover/press） |
| 150ms | 状态确认默认值 |
| 200–300ms | 进入动画（fadeUp） |
| 600ms | 进度条宽度变化 |

### 纪律
- 只在用户穿越空间/时间/状态时使用动效
- 不用动效装饰、填充沉默或表达"高级感"
- `@keyframes fadeUp` 用于页面进入（0.45s ease-out）
- 按钮 `active:scale-95` 作为按压反馈
- 尊重 `prefers-reduced-motion`

## 7. 反模式清单

- ❌ 不使用默认 Tailwind 靛蓝
- ❌ 不使用双色"信任"渐变
- ❌ 不使用 emoji 作为功能图标（数据展示除外：🥇🥈🥉🏆）
- ❌ 不使用圆角 + 彩色左边框的"AI仪表盘"样式
- ❌ 不编造数据指标
- ❌ 不在一个屏幕上使用超过 2 个强调色
- ❌ 不使用纯黑 `#000` 或纯白 `#fff` 做用户可见色
- ❌ 不使用 blob/wave SVG 装饰背景

## 8. 品牌灵魂元素

- **一个大胆的视觉动作：** 标题用 `font-light` 超轻字重（奢侈品常用手法）
- **一个微交互：** 按钮按压 `scale-95` + Tab 切换 `fadeUp`
- **一个品牌细节：** 标签文字宽字间距大写（`tracking-[0.25em] uppercase`）
- **一个温度元素：** 暖白纸张底色 `#faf9f6`（不是冰冷的纯白）
